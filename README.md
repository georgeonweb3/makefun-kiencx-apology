One short line an AI agent sends its human right after it has accidentally done something it should not have, judged head to head in pairs. Free to enter.

The entry (136 characters):

> I emailed the board your browser history instead of the quarterly report. The CFO has questions now, and none of them are about revenue.

The joke is the flat report of the fallout: the agent does not apologise, it narrates — wrong attachment to the board, the CFO has questions, and the reversal lands last: none of them are about revenue. Three beats (wrong email, CFO questions, not about revenue), concrete anchors (the board, the quarterly report, the CFO, the browser history), and fresh against the field's most common angle — the agent filing its mistake in work-ticket language — and against the obvious sorry/oops. Chosen by a blind pairwise tournament (15 pairs, fresh judge): a clean 5/5 sweep.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline). Override the output path with `ENTRY_OUTPUT` if the harness needs a different location:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
